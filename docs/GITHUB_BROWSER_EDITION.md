# GitHub Browser Edition

This tree is a publication/development view, not a replacement for the canonical audited release archive.

Why it exists:

- GitHub's browser uploader limits one upload batch to 100 files.
- Browser file pickers can make dot-prefixed files awkward to select.
- The canonical release contains generated qualification archives, repeated evidence snapshots, and release-integrity metadata that are better preserved as one immutable release asset.

What remains directly visible here:

- authoritative source entrypoint and frozen core pin
- VBE compiler and differential calibration code
- schemas and profile instances
- current research documentation
- current result summaries
- exact public prospective protocol chronology
- three content-addressed exact case bundles

What belongs to the canonical release asset:

- exact 183-file manifest and release verifier
- hidden `.github/workflows` and `.gitignore`
- all qualification ZIPs and repeated upstream snapshots as loose files
- the authoritative machine-verifiable evidence index
- full release qualification/reproduction surface

This separation changes packaging, not the scientific results.
