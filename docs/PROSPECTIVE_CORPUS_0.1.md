# Prospective Corpus 0.1

The first prospective VBE corpus is intentionally not a bug hunt.

The exact protocol bytes were locally sealed before Case 004 candidate screening at:

`9fbf3fcdf48e5554840c4f2418803779ad82757e1a5df71411212421c225ad70`

The design fixes an enrollment target of eight eligible units, prohibits result quotas and verdict-driven replacement, requires screening/rejection logs, requires a manual acquisition-friction ledger, caps any one organization at two units, and requires at least four independent organizations and three carrier/mechanism families.

A public Git commit of the exact bytes is mandatory before screening. An automated publication attempt to the public RISU Institute repository failed because the current GitHub integration lacks contents-write permission. Therefore the gate remains **closed**. No Case 004 candidate may be screened under this protocol until the external timestamp record is completed.

After external publication, the protocol cannot be edited in place. Any change requires a numbered amendment that records whether screening or verdict observation had begun.
